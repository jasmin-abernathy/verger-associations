# Security policy

## Supported code

The current `main` branch is the only branch considered for security fixes while the project is an early pilot.

## Reporting a vulnerability

Please do not disclose vulnerabilities, private group content or test data in a public issue.

Send a private report to `contact@lepotager.org` with the subject `Security — Verger Associations`. Include the affected commit, reproduction steps and likely impact.

Use synthetic data. Do not attach real association member lists, private discussions, meeting exports, access tokens or deployment secrets.

Particular care should be given to Webxdc packaging, imported/exported data, permissions and any future synchronisation layer.
